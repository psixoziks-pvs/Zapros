# Словарь языка Славовце (для вывесок, фамилий и названий)

Все слова построены на корнях из вашего личного списка имён. Ниже — 12 корней-основ,
из которых собираются ВСЕ слова города, и полный перевод каждого названия мода.

---

## ЧАСТЬ 1. КОРНИ (12 священных основ языка)

| Корень | Значение | Примеры слов |
|---|---|---|
| **slav-** | славный, свет славы, почитание | Slavovce, Slava, Zdenislav |
| **vod-/ved-** | вода, река, течение, поток | Vodnik, Vltava→Vodice, Hluboká→Hlubokovod |
| **les-/lis-** | лес, чаща, древесный мир | Lesny, Lisin, Svetolet |
| **hrad-/dvor-** | город, двор, крепость, дом | Hradek, Dvorce, Radhost |
| **pole/niva-** | поле, нива, пашня, урожай | Nivany, Polabsko→Polanov |
| **hora-** | гора, холм, вершина, подъём | Horin, Vysoké→Vyslav |
| **kamen-** | камень, скала, фундамент, вечность | Kamenic, Olskrmen |
| **zlat-/světlo** | золото, свет, солнце, сияние | Zlata, Svetozar, Svetla |
| **žito/mlyn (mel-)** | зерно, хлеб, мука, мельница | Zitonog, Mlecany |
| **řeka (rek-)** | река, путь воды, рыбная тропа | Rekovan, Rybrec |
| **ohně/žár (var-)** | огонь, жар, кузня, обжиг | Varany, Ohnislav |
| **drúha/soused (rod-)** | община, род, соседство, союз | Rodiny, Susedlany |

Правило словообразования: **корень + суффикс**. Суффиксы:
`-ovce/-any/-ice` (город/поселение), `-ak/-ec` (мастер-мужчина), `-ka` (женщина-мастер),
`-ov/-in` (притяжательное «чей»), `-sky` (принадлежность месту/профессии).

## ЧАСТЬ 7. СПРАВОЧНАЯ ТАБЛИЦА: КАК САМОМУ СОБИРАТЬ СЛОВА

1. Возьми корень по смыслу (вода=vod, лес=les, огонь=var…).
2. Добавь окончание места: **-ovce, -any, -ice, -sko, -ec**.
   - pekárna u řeky → **PEKOVAREC** (pec+rek)
3. Для мастера: корень + **-ak/-ec/-ar**; для женщины: **+ka**.
   - rytec (резчик) → **KRMENEC**; резчица → **KRMENKA**
4. Для прилагательного-вывески: корень + **-ovy/-sky**:
   - «золотая башня» → **ZLATOVEŽSKÁ VEŽ**
5. Сохраняй мягкость: ć/ď/ť/ň, ů, ě — тогда язык читается как ваш список имён.
